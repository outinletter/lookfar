알림이 보이지 않아요

iPhone 설정 → 알림 → LookFar에서 알림 허용과 배너를 켜주세요. 집중 모드, 무음 모드, 알림 요약 설정도 확인해 주세요. 시작 버튼을 눌러 타이머를 예약해야 알림이 전송됩니다. 타이머마다 한 번 알리며 실제 스마트폰 사용 시간을 감지하지 않습니다.

Dynamic Island가 보이지 않아요

지원 기기에서 실시간 현황이 허용되어야 합니다. LookFar 설정의 잠금 화면 · Dynamic Island를 켠 후 새 타이머를 시작해 주세요. Dynamic Island 표시와 확장은 iOS가 제어하며 종료 알림은 별도의 배너입니다.

기록을 삭제하고 싶어요

설정 → 모든 데이터 초기화로 알림, 타이머, 휴식 기록과 설정을 삭제할 수 있습니다.
