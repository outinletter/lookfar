알림이 보이지 않아요

iPhone 설정 → 알림 → LookFar에서 알림 허용과 배너를 켜주세요. 집중 모드, 무음 모드, 알림 요약 설정도 확인해 주세요. 시작 버튼을 눌러 타이머를 예약해야 알림이 전송됩니다. 타이머마다 한 번 알리며 실제 스마트폰 사용 시간을 감지하지 않습니다.

Dynamic Island가 보이지 않아요

지원 기기에서 실시간 현황이 허용되어야 합니다. LookFar 설정의 잠금 화면 · Dynamic Island를 켠 후 새 타이머를 시작해 주세요. Dynamic Island 표시와 확장은 iOS가 제어하며 종료 알림은 별도의 배너입니다.

앱을 열 때 타이머 자동 시작

LookFar에서 시간을 정하고 알림을 한 번 허용한 뒤, Apple 단축어 → 자동화 → 앱 → 원하는 앱 → 열릴 때 → 즉시 실행을 선택하세요. LookFar의 ‘눈 휴식 타이머 시작’ 동작을 추가해 저장하면 됩니다. 진행 중인 타이머는 유지됩니다. 매번 전체 시간으로 초기화하려면 ‘눈 휴식 타이머 새로 시작’을 선택하세요. LookFar 설정에도 자세한 안내가 있습니다.

화면 켜짐·잠금 해제 감지 기능은 아닙니다. 화면을 꺼도 타이머는 계속되며 화면을 켜는 것만으로 초기화되지 않습니다. 자동화를 중단하려면 단축어에서 삭제하거나 비활성화하세요.

기록을 삭제하고 싶어요

설정 → 모든 데이터 초기화로 알림, 타이머, 휴식 기록과 설정을 삭제할 수 있습니다. 단축어 자동화는 단축어 앱에서 별도로 삭제해야 합니다.
